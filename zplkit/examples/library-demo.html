ZPLkit

Dieselbe ZPL-Logik wie in ZPL-Studio, ohne Studio-UI – zum Einbinden in andere Tools. Diese Seite lädt ausschließlich ein Bundle aus dist/.

Geladenes Bundle: …   full laden lite laden

Einbinden

<script src="zplkit-full.js"></script>
<script>
  const label = ZPLkit.parse(zplText);   // ZPL-Text  -> Objektmodell
  label.elements[0].x = 100;             // beliebig verändern
  const out = ZPLkit.generate(label);    // Modell -> ZPL-Text
</script>

In Node/CommonJS: const ZPLkit = require('./zplkit-full.js');
